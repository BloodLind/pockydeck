AGP 8.7 officially requires Gradle 8.9 and JDK 17, supports API 35 at most, and defaults to Build Tools 34.0.0: [AGP 8.7 compatibility](https://developer.android.com/build/releases/agp-8-7-0-release-notes). Kotlin 2.x Compose modules use the matching Compose compiler Gradle plugin: [Compose compiler migration guide](https://kotlinlang.org/docs/compose-compiler-migration-guide.html). Room 2.7 supports Kotlin 2 and recommends KSP2: [Room release notes](https://developer.android.com/jetpack/androidx/releases/room#2.7.0).

On this host, Java needs a process-local Unix-domain socket directory for Gradle's client and child JVMs. This is a host workaround under ignored `.local/`; it is not a source or system setting.

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
$env:ANDROID_HOME = 'C:\Users\TakeIt4mo\AppData\Local\Android\Sdk'
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
New-Item -ItemType Directory -Force -Path '.local/java-tmp' | Out-Null
$env:JAVA_TOOL_OPTIONS = '-Djdk.net.unixdomain.tmpdir=.local/java-tmp'
.\gradlew.bat --no-daemon assembleDebug lintDebug :core:domain:test :app:testDebugUnitTest
```

Result: **passed**, `BUILD SUCCESSFUL in 1m 1s`, 137 actionable tasks. The first build attempt failed before compilation because AndroidX Core 1.15.0 requires compileSdk 35. The pin was corrected to API-34-compatible Core 1.13.1; the command above then passed. Lint completed with zero errors. App lint reported 48 non-blocking warnings, primarily deliberate pinned-version and targetSdk notices plus the absent final launcher icon; data and design-system lint reported no issues.
