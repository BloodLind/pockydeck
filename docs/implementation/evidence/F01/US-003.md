## Acceptance evidence

### AC-01 — Stable destinations, compact snapshots and origins

Passed by `NavigationContractTest`. It verifies the exact stable dock order Home/Library/Apps/Favorites/Settings/Search, non-Home dock Back to Home, root Home staying open, shortcut Search returning to its initiating destination, and details returning to a shortcut-Search origin. Locations contain the current origin only, with no Compose object or history list.

The test repositories also verify independent Home and Search snapshots containing stable selected/anchor IDs, non-negative offset, query, filter and sort keys while an untouched Apps snapshot remains absent.

### AC-02 — One action meaning and explicit controller default

Passed by `SharedPresentationContractTest` and `NavigationContractTest`. The exact `LauncherActionDescriptor` rendered by `ControllerActionFooter` is passed to `SemanticActionPort`, and duplicate meanings for one semantic input are rejected. `ConfirmBackMapping.Default` is A-confirm/B-back; swapped mapping remains typed. The fixed dispatch-owner order is IME, modal, focused page/control, shell.

### AC-03 — Independent modal and truthful status contracts

Passed by compilation and focused tests. `core:designsystem` compiles independently with `ModalFocusLifecycle` under its own package and no product-module imports. Status tests distinguish available, unavailable and unsupported states; app presentation renders `—` for unavailable and omits unsupported optional values.

### AC-04 — Activity side effects are claimed once

Passed by `ActivityRequestPortTest`. A request is removed from observation by atomic `claim` before execution. Two synchronized competing consumer threads produce exactly one claim. A wrong ID, repeated observation, second claim, lifecycle-style reattachment after claim, repeated completion, and resubmission of a completed ID cannot replay it. Completion acknowledgement remains a separate operation.

The production `MainActivity` uses this order and safely completes the current scaffold request as `Unsupported`. Android launch and HOME-role side effects remain F07/F08 work.
