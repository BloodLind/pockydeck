# Product Requirements Document (PRD) & Design Brief
## Project: Minimalist Android Handheld Gaming Launcher OS

---

### 1. Executive Summary & Vision
The **Android Handheld Gaming Launcher** is a custom front-end OS interface built specifically for dedicated Android gaming handhelds (such as Retroid Pocket, Odin, and Anbernic devices) equipped with 16:9 widescreen displays (1920×1080 target resolution). 

Drawing inspiration from the ergonomic simplicity and physical playfulness of the **Nintendo Switch OS** and classic console tactile cues (GameCube/Retroid button accents), the system delivers a lightweight, lightning-fast, zero-clutter launcher experience that bridges retro emulation, native Android games, and system utilities into a unified TV/handheld console environment.

---

### 2. Design Principles & Aesthetic Direction
1. **Tactile & Toy-like Simplicity**:
   - Soft-touch dark graphite and subtle charcoal-purple backgrounds (`#161922` / `#1c1f2b`).
   - Clean, rounded geometry without glossy 3D bevels, skeuomorphism, or overwhelming neon glow.
   - Physical gamepad-inspired contrast: Crisp tactile light-gray buttons, GameCube green `[A]` (Confirm/Launch), alert red `[B]` (Back/Cancel), and an unmistakable amber/yellow controller focus ring (`#eab308` / `#f59e0b`).
2. **Physical-First Controller Navigation**:
   - 100% operable via physical gamepad buttons (D-Pad, Analog Stick, ABXY, Bumpers/Triggers, +/-).
   - Clear distinction between **Active Page Destination** (Dock tab highlighted) and **Controller Focus** (amber highlight ring on focused tile/button).
   - Instant visual response with zero input latency.
3. **Ergonomic Widescreen (16:9) Layout**:
   - Fixed 1920×1080 proportioned canvas with balanced vertical spacing and zero horizontal screen cutoff on handheld screens (5.5" to 6").
   - Persistent top telemetry header and centered bottom navigation dock anchored above controller action hints.

---

### 3. Core Architecture & Screen Flows

#### A. Shared Persistent Shell
- **Top Telemetry Header**:
  - Left: Handheld status / Battery % + Icon, Wi-Fi signal status, Bluetooth indicators.
  - Right: System clock (12h/24h) and ambient temperature / performance profile tag.
- **Bottom Navigation Dock**:
  - Strict destination order: `Home` → `Library` → `Apps` → `Favorites` → `Settings` → `Search`.
  - Flanked by physical bumper hints: `[ L1 ]` (Previous Tab) and `[ R1 ]` (Next Tab).
- **Controller Action Footer**:
  - Dynamic button prompts matching controller state: `(A) Play/Select`, `(B) Back`, `(X) Search`, `(Y) Details`, `(+) Menu/Options`.

#### B. Key Screen Specifications
1. **Home Launcher (Screen Reference: SCREEN_6)**:
   - **Hero Carousel**: Horizontal cartridge carousel displaying recent titles with square/1:1 cover art containers.
   - **Focused Stage**: Enlarged active cartridge with yellow bezel outline, subtitle info (Platform, Playtime, Last Played), and instant launch trigger.
2. **Library Hub (Unified Collection)**:
   - **Structure**: Vertically scrolling 6-column grid featuring retro ROMs, native Android games, standalone emulator apps, and utilities without artificial segregation.
   - **Platform Filter Strip**: `All`, `Android`, `GameCube`, `PSP`, `PS2`, `GBA`, `More`.
   - **Artwork Fallbacks**: Dynamic stylized icon cards for apps/ROMs lacking scrape metadata.
   - **Empty State UX**: Informative setup flow for unconfigured platforms without forcing manual directory scans as standard workflow.
3. **Game Details & Launcher Hub**:
   - Full-screen game backdrop artwork, synopsis, and playtime analytics.
   - Emulator core selector (e.g. Dolphin vs. RetroArch core), save-state management, and controller remapping shortcuts.
4. **Quick Settings & Performance HUD Overlay**:
   - Low-latency slide-over drawer accessible in-game via hotkey.
   - Sliders and quick toggles: TDP power limit, GPU clock scaling, fan curves, FPS limiter (30/60/90), display brightness, and audio volume.

---

### 4. Technical & Implementation Requirements
- **Target OS**: Android 11 / 12 / 13 (AOSP handheld branch).
- **Display Target**: 1920×1080 (16:9), 60Hz/120Hz refresh rates, calibrated for 5.5" to 6.0" IPS/OLED touchscreens.
- **Input Specifications**: Standard Android KeyEvents (Gamepad buttons: `KEYCODE_BUTTON_A`, `KEYCODE_BUTTON_B`, `KEYCODE_DPAD_*`, etc.).
- **Asset Standards**: Square 1:1 boxart metadata scraper (SteamGridDB / Screenscraper API integration).

---

### 5. Roadmap & Next Deliverables
1. **Phase 1 (Complete)**: Home Launcher 16:9 locked design system and palette tokens.
2. **Phase 2 (In Progress)**: Comprehensive Library Grid and state variations (Filters, Controller Focus, Missing Artwork Fallback, Empty Platform).
3. **Phase 3**: Game Details Hub and Quick Settings Overlay.
4. **Phase 4**: Android native frontend prototype and key mapping configuration.
