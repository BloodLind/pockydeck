# PockyDeck 0.10.3 — first public preview

Released 9 September 2026. Android 13+, version code 17, package `dev.handheld.launcher`. Android still displays the app as Handheld Launcher.

## Download

Download `pockydeck-0.10.3-preview.apk`, `SHA256SUMS.txt`, and `SIGNING_CERTIFICATE.txt` from [GitHub Releases](https://github.com/BloodLind/pockydeck/releases/tag/v0.10.3).

This is a non-debuggable release-variant APK signed with the existing development certificate. It excludes the debug preview screens and their fixtures. The signing certificate permits updates from earlier project builds using the same key; arbitrary local debug builds may use a different key. See [installation and signing](../getting-started.md#install-the-preview).

## Included

Home, Library, Apps, Favorites, Search, Settings, Android app discovery, ROM-folder scanning, supported emulator/RetroArch choices, archive preparation, ES-DE/optional Libretro artwork, PC frontend exports, controller acceleration, original sound effects, grid/list layouts, UI scaling, and optional Shizuku process indicators.

The latest UI refinements make action buttons quieter and smaller while preserving full touch targets, simplify the collapsed Search toolbar, and keep three complete console categories visible where space permits.

The public repository now includes Apache 2.0 licensing, current guides, contribution/security policies, issue and pull-request templates, and automated build checks. Historical planning/logs/screenshots have been removed from the current tree, and debug cover samples have been replaced with original vectors.

## Verification

Before the publication cleanup, 0.10.3 passed 309 JVM tests and 50 distinct Android checks on a physical Retroid Pocket Flip 2 running Android 13. One Windows-only symlink fixture was skipped. Device coverage included long held-D-pad Search navigation, row traversal, focus restoration, compact controls, and larger font scale.

The publication pass passed the combined debug/release build, JVM, and lint checks: 309 passing tests, one existing Windows fixture skipped, zero lint errors, and 65 lint warnings. Documentation links, packaged license assets, release manifest, signature, and checksums were checked. No physical device was connected during publication, so the freshly packaged release APK does not claim a new device smoke test.

## Known limits

This is a preview. Emulator detection or accepted launch intents do not establish game compatibility, installed cores, BIOS/keys, or successful gameplay. Several emulators are detection-only. RAR, encrypted/nested archives, and emulator-native image conversion are unsupported.

PC games require supported frontend exports. Missing PC covers do not receive a Libretro lookup. Live process badges require Shizuku, appear only on Home, and do not identify which ROM is playing. Temperature is battery temperature.

See the [roadmap](../roadmap.md), [format matrix](../rom-formats.md), and [emulator matrix](../emulators.md). Report problems with device, Android/app/emulator versions, input method, and reproduction steps; do not attach games or personal data.
