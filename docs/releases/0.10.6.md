# PockyDeck 0.10.6 preview

A free Android handheld launcher focused on a familiar console-style experience.

Supports controller and touch navigation with Xbox or Nintendo/retro button labels; Home, Library, Apps, Favorites, and Search; ROM scanning and supported emulator/RetroArch choices; grid/list views; local and optional online artwork; customizable backgrounds and 90–150% UI scaling; and adjustable sound and vibration. Button labels can be changed in Settings → Controls without changing the physical controls.

Download `pockydeck-0.10.6-preview.apk` from the [release assets](https://github.com/BloodLind/pockydeck/releases/tag/v0.10.6). Requires Android 13+. No games, BIOS files, emulators, or cores are included. Root and Shizuku are not required.

This release uses the same signing certificate as previous official previews and supports an in-place update. Checksums and the certificate fingerprint are included with the APK. See [setup](https://github.com/BloodLind/pockydeck/blob/v0.10.6/docs/getting-started.md) and [emulator compatibility](https://github.com/BloodLind/pockydeck/blob/v0.10.6/docs/emulators.md).

This is a preview, tested primarily on the Retroid Pocket Flip 2. 4:3 screens do not work well and are not properly supported. Widescreen formats work well, with possible minor alignment offsets. Other devices and emulator versions may behave differently.
